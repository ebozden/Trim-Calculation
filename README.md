# Aircraft Trim Point Optimization using Powell's Method

This project focuses on calculating trim conditions for different flight phases of a fixed-wing aircraft using MATLAB and the Powell optimization algorithm.

## ✈️ Objective

Determine the trim points for:
- **Level flight**  
- **Steady climb**  
- **Steady coordinated turn**

using a custom dynamic model of the aircraft and unconstrained Powell optimization.

## ⚙️ Tools & Techniques

- MATLAB for aircraft modeling and optimization  
- Powell’s method for multivariable optimization  
- Flight dynamics equations representing steady-state conditions  
- Objective function based on minimizing total forces and moments
